Copyright (C) The Battle for Wesnoth Project

These 40 fantasy portraits come from [The Battle for Wesnoth](https://www.wesnoth.org/), pinned to commit [eeea9ac0361a6e98f1f6e85b746f15bd65210586](https://github.com/wesnoth/wesnoth/commit/eeea9ac0361a6e98f1f6e85b746f15bd65210586). **The original images in [originals/](originals/) are unmodified, byte-for-byte upstream files**, including their embedded artist and copyright notices. Display names are labels chosen by RPG Token Maker, not upstream character names.

## Verification and first additions

[sources.json](sources.json) records SHA-256 checksums, upstream Git blob IDs, dimensions read from the source files, and per-file first-addition dates and Git commit authors obtained with `git log --follow --find-renames=100%`. Git commit authors and artists are recorded separately. The date of a format conversion, optimization, or EXIF metadata update is not treated as the original contribution date.

The pinned commit's `copyrights.csv` contains audio records only. [Commit f684c20](https://github.com/wesnoth/wesnoth/commit/f684c20dac0392ea6b8b960706ad07c655b7111a) removed its image rows; [commit 0330122](https://github.com/wesnoth/wesnoth/commit/033012219e737f8c1bca288e16700a8795e67117) explicitly replaced image copyright tracking with embedded EXIF artist and copyright tags. We checked the last image-bearing [official CSV](https://github.com/wesnoth/wesnoth/blob/d4b2d151ce3413f8765530c1de0a3a8109dda534/copyrights.csv), preserved the relevant [CSV rows](copyrights-excerpt.csv), and compared every image's current EXIF license. All 45 audited records (40 library entries and five existing samples) agree on their licenses. The explicit CC0 entry takes precedence over the date-based default in [Wesnoth's copyright policy](https://wiki.wesnoth.org/Wesnoth:Copyrights).

## Transformations and reproduction

RPG Token Maker serves these unchanged originals from `/library/<id>.webp`. Its separate `/library/thumbs/<id>.webp` previews are **modified** copies: resized to fit within 192 × 192 pixels with aspect ratio and transparency preserved, encoded as WebP, and retaining upstream metadata. Their respective licenses remain as listed above. Adding a frame, fill, crop, or name in the tool produces a modified token; keep the relevant notices and license terms when distributing it. No watermark is added.

The repeatable [build script](https://github.com/TuringHuang/rpg-token-maker/blob/codex/art-library/scripts/build-art-library.mjs) uses sharp 0.34.5 / libwebp 1.6.0, checks each input against the pinned SHA-256, reads image dimensions, copies originals without decoding/re-encoding, then generates thumbnails and the lazy-loaded catalog. Run `node scripts/build-art-library.mjs` in that repository. Use `--source-dir <directory>` for these originals, `--check` to verify all outputs without writing them, and `--audit-history <full-wesnoth-clone>` to repeat all 45 first-addition checks.

The five existing homepage samples are separately documented under [samples/](../samples/). All five remain GPL-2.0-or-later. The library's Assassin shares the upstream portrait used by the Vex sample; the library keeps the transparent, unmodified original.
